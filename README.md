# Personal Portfolio — Shravya Somayaji

A personal developer portfolio showcasing my projects, technical skills, education, experience, and achievements as a Computer Science Engineering student.

## 🌐 Live Website

**[View My Portfolio](https://personal-portfolio-eight-phi-72.vercel.app)**

## ✨ Features

- **Home:** Introduction, portrait, social links, and portfolio navigation.
- **About:** Background, academic highlights, skills, and extracurricular activities.
- **Education:** Academic journey and qualifications.
- **Projects:** Selected software development and machine learning projects.
- **Experience:** Internship and learning experiences.
- **Skills:** Programming languages, web technologies, databases, and ML/AI tools.
- **Achievements:** Highlights and accomplishments.
- **Contact:** Contact information and social profiles.

## 🛠️ Tech Stack

- **Frontend:** React, JavaScript, HTML, CSS
- **Build Tool:** Vite
- **Animations:** GSAP
- **Routing:** React Router
- **Deployment:** Vercel
- **Version Control:** Git and GitHub

## 🚀 Run Locally

Prerequisites: Node.js and npm.

1. Clone the repository:

   ```bash
   git clone https://github.com/shravya0306/Personal_Portfolio.git
   ```

2. Navigate to the application directory if needed:

   ```bash
   cd Personal_Portfolio/portfolio
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal.
